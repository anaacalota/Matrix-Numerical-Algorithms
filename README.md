# Matrix Numerical Algorithms

## 1. Markov is coming..

- The code implements maze traversal as efficiently as possible,
  using heuristic search algorithms and iterative methods for
  linear systems.

**Implementation**

- `parse_labyrinth()` reads the maze configuration from a file and
  stores it in a corresponding numeric matrix.
- `get_adjacency_matrix()` generates the adjacency matrix based on the walls
  of each node.
- `get_link_matrix()` builds the link matrix by counting the number of
  neighbors in each row, then dividing each 1 that corresponds to a neighbor
  by the number of neighbors.
- `get_Jacobi_parameters()` returns the parameters from the link matrix
  that are needed to solve equations using the Jacobi method.
- `perform_iterative()` uses the Jacobi method to solve a system of linear
  equations based on the link matrix.
- `heuristic_greedy()` finds the path through the maze, choosing the best
  unvisited neighbor at each step. If no neighbors are available,
  the algorithm backtracks, removing the last node added to the path.
- `decoded_path()` traverses the path that was found and prints the positions
  in terms of the maze's rows and columns.

## 2. Linear Regression

- The program implements various regression models for solving linear and
  regularized regression problems.
- It uses algorithms such as gradient descent, normal equations, and
  regularization techniques such as Lasso regression and Ridge regression.

**Implementation:**

- `parse_data_set_file()` reads a dataset from a file, building the initial
  matrix and the vector of actual values.
- `prepare_for_regression()` iterates through the rows of the initial matrix
  and, depending on the values found, creates the FeatureMatrix according to
  the specified requirements.
- `linear_regression_cost_function()` uses the least squares method to find
  the best theta. It is computed as the sum of the squared differences
  between the predictions and the actual values.
- `parse_csv_file()` reads a CSV file and extracts the features to be used
  in the regression models.
- `gradient_descent()` uses the gradient descent method to optimize the cost
  function in regularized and linear regression, computing theta step by step.
- `normal_equation()` directly computes the theta parameters using the
  Normal Equation method.
  I checked whether the matrix is positive semidefinite by computing its
  eigenvalues and making sure they are positive, using the logic from [1].
- `lasso_regresion_cost_function()` uses L1 regularization, which helps with
  feature selection by shrinking the coefficients of less important features.
- `ridge_regression_cost_function()` implements the L2 regularization formula.

## 3. MNIST 101

- The code implements the training and optimization of a simple neural
  network for classification tasks, using algorithms such as forward
  propagation and backpropagation.

**Implementation:**

- `load_dataset()` loads the file into memory.
- `split_dataset()` shuffles the rows of matrix X and of y using the
  permutation generated by `randperm` [2]. It puts the first given percentage of
  the examples into `X_train` and `y_train`, and the rest into `X_test` and `y_test`.
- `initialize_weights()` computes epsilon according to the formula and
  generates the matrix with values between (-epsilon, epsilon).
- `cost_function()` computes the error based on the predictions and the actual
  values, using forward propagation and backpropagation. I used `y_eye` to
  convert the vector y into a matrix that contains a single 1 per row,
  marking the correct class of the example, with all other entries being 0.
